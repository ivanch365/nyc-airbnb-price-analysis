# 🏙️ NYC Airbnb Price Analysis

## Overview

This project presents an exploratory data analysis (EDA) and machine learning workflow using the **NYC Airbnb Open Data** dataset. The objective is to better understand the characteristics of Airbnb listings in New York City and build regression models capable of predicting listing prices from property, host, and location features.

The project follows a complete data science pipeline, including data exploration, preprocessing, feature engineering, model development, and performance evaluation.


## Dataset

The dataset contains **48,895 Airbnb listings** across New York City with a mixture of numerical, categorical, textual, and geographic features.

Examples of available information include:

* Listing price
* Room type
* Neighbourhood and borough
* Geographic coordinates
* Availability
* Number of reviews
* Host information
* Review activity


## Project Objectives

* Perform exploratory data analysis to better understand the dataset
* Identify relationships between listing characteristics and price
* Handle missing values and prepare the data for modeling
* Engineer meaningful features where appropriate
* Compare multiple regression algorithms
* Evaluate model performance using appropriate regression metrics


## Workflow

The project follows the standard machine learning pipeline:

1. Data exploration and visualization
2. Data cleaning
3. Feature engineering
4. Data preprocessing
5. Baseline model
6. Linear regression models
7. Tree-based regression models
8. Model comparison
9. Hyperparameter tuning
10. Model evaluation
